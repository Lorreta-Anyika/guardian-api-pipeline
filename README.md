# ETL Job with emphasis on Docker and Github actions

![Docker Image](https://img.shields.io/badge/docker-lorreta2025%2Fguardian--etl-blue)

Minimal Python script that consumes the Guardian API.

This repository documents the step-by-step evolution of the project
from a simple script to a more production-ready data pipeline.
